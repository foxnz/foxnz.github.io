This is the first post on my site. I'll use it to write up things I'm building and learning, mostly:

- **LLM and RAG applications**: what works, what breaks, and how I check the output.
- **Computer vision in manufacturing**: notes from my PhD on real-time weld inspection.
- **Side projects**: build logs, like the peer-to-peer Watch Party app.

## How this site works

It's built with [Astro](https://astro.build/) and hosted on GitHub Pages. Each post is one Markdown file in `src/content/posts/`. Pushing to GitHub rebuilds and publishes the site.
